# 🎮 Game Screen Translator (Arknights & Others)

Легковесный переводчик текста в реальном времени для игр без официальной локализации. 
Программа делает скриншот, распознает текст с помощью нейросетей (локальных или облачных) и выводит перевод прямо поверх игры в виде аккуратного клик-сквозного оверлея.

Изначально создавался для чтения сюжета в **Arknights**, но отлично работает и с другими играми.

## ✨ Возможности
- **3 режима перевода:** 
  - ☁️ **Облачный API** (TokenHarbor, OpenRouter и любые OpenAI-совместимые шлюзы). Быстро и не грузит ваш ПК.
  - 🖥️ **LM Studio** (Локальный AI). Приватно, бесплатно, работает без интернета.
  - 🔍 **Классический OCR** (EasyOCR + Argos) — полностью офлайн (доступно только при запуске из исходников).
- **Умный захват экрана:** Для Arknights программа захватывает только нижнюю часть экрана (диалоги), экономя токены API в 5-10 раз.
- **Удобный оверлей:** Окошки с переводом не перехватывают клики мышью, не перекрывают интерфейс и не вызывают панель задач Windows.
- **Горячие клавиши:** `F8` — перевести, `F9` — убрать текст, `F10` — полностью закрыть программу.
- **Пульт управления:** При запуске открывается аккуратное окошко с настройками и кнопкой выхода.

## 🚀 Установка и запуск

### Вариант 1: Готовый `.exe` (Для обычных пользователей)
*Скачайте последний релиз в разделе [Releases](../../releases).*
1. Распакуйте архив в любую папку.
2. Запустите `GameTranslator.exe` **от имени администратора** (иначе игра может перехватывать нажатия F8/F9).
3. В открывшемся окне выберите настройки:
   - **Режим захвата:** Arknights (только диалоги) или Полный экран.
   - **Движок:** Укажите ваш API (URL и Ключ) или выберите LM Studio.
4. Нажмите «Сохранить и запустить». Появится пульт управления.

### Вариант 2: Запуск из исходников (Для разработчиков)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Jenkash/LM_translator.git

2. Установите базовые зависимости:
   pip install -r requirements.txt

3. Запустите:
   python main.py (от имени администратора)


🎮 Как пользоваться
Запустите игру в оконном режиме без рамки (Borderless Windowed).
Находясь в игре, нажмите F8. Подождите пару секунд.
Поверх английского текста появится перевод.
Нажмите F9, чтобы убрать текст, или F10, чтобы завершить работу программы.

🛡️ Антивирус и ложные срабатывания
Из-за того, что программа перехватывает нажатия клавиш (через библиотеку pynput) и собрана с помощью PyInstaller, Windows Defender или антивирусы (например, Kaspersky) могут ложно определить её как «кейлоггер» или троян. Это нормальная реакция на неподписанные .exe файлы, использующие глобальные хоткеи. Добавьте программу в исключения антивируса.

🖥️ Как включить полностью офлайн-режим (Локальный OCR)
По умолчанию в requirements.txt закомментированы тяжелые библиотеки (easyocr, argostranslate), чтобы pip install проходил быстро и не занимал 4 ГБ. Если вы хотите переводить текст без интернета:

Откройте requirements.txt и раскомментируйте easyocr и argostranslate.

Установите их: pip install easyocr argostranslate.

Установите PyTorch с поддержкой CUDA (инструкции на официальном сайте pytorch.org).

В настройках укажите движок "local" (или в config.py установите VISION_ENGINE = "local").
